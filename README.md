## 💻 Le Site Web Portfolio : Présentation & Fonctionnalités

Ce site portfolio est conçu comme un **centre de commandement Cyber / SOC (HUD)** immersif, ultra-moderne et performant, valorisant les compétences techniques à travers des composants interactifs originaux.

### ✨ Fonctionnalités Implémentées

1. **Esthétique Cyber HUD & Glassmorphism**
   - Palette dark cyberpunk soignée : touches néon Cyan (`#00f2fe`), Violet néon (`#a855f7`), Vert émeraude (`#00ff87`) et Rose accent (`#f43f5e`).
   - Scanlines CRT rétro-futuristes discrètes, halos ambiants immersifs et cartes en verre flouté (*backdrop-filter: blur*).
   - Cadre photo cyber au format carré 1:1 avec coins de visée HUD et télémétrie active.

2. **Fond Interactif Neural Canvas**
   - Toile Canvas 2D fluide avec réseau de nœuds et particules réactives aux mouvements de la souris, simulant un maillage de télécommunications interactif.

3. **Moteur Sonore Cyber (Web Audio API)**
   - Synthétiseur audio natif produisant des effets sonores (SFX) subtils lors des interactions (clics, survol, boutons). Bouton bascule audio présent dans l'en-tête (`SFX: ACTIF / MUET`).

4. **Console Interactive CLI (`Fataki-OS v4.2`)**
   - Véritable émulateur de terminal en ligne de commande Unix/SecOps directement dans le navigateur :
     - Commandes supportées : `whoami`, `skills`, `kali`, `onion`, `csharp`, `projects`, `cve`, `certs`, `contact`, `matrix`, `clear`, `flag` (easter egg CTF).
     - Raccourcis cliquables rapides au-dessus de la console pour une exploration sans saisie manuelle.
     - Prise en charge de l'historique des commandes avec les touches Flèche Haut / Bas.

5. **Grille de Projets avec Filtrage Dynamique**
   - Études de cas réelles :
     - *Fine-Tuning Radio FAI (54 sites)* : décongestion de trafic et optimisation RF.
     - *Boucle Locale & V-SAT* : stations terriennes haut débit et routage multi-constructeurs.
     - *Cadre Forensic SI Hybrides RDC* : méthodologie de collecte d'artefacts et chaîne de traçabilité.
   - Système de filtrage instantané par catégorie (*Tous*, *Télécoms & Radio*, *Infrastructures & V-SAT*, *Recherche Forensic*).

6. **Tableau des Audits, CVE & Modales d'Investigation**
   - Tableau technique récapitulant les missions d'audit et axes de recherche (ISO 27001, durcissement de bases de données MySQL/PostgreSQL, QoS radio).
   - Modale interactive avec télémétrie complète, vecteurs d'attaque et contre-mesures détaillées.

7. **Simulateur d'Audit Interactif (Audit Estimator)**
   - Outil de configuration permettant aux entreprises d'estimer en temps réel la durée, la méthodologie (ISO 27001, Pentest Cisco, Forensic) et les livrables recommandés selon leur infrastructure.

8. **Canal Sécurisé & Chiffrement PGP**
   - Formulaire de prise de contact direct pour propositions de missions ou audits sous NDA.
   - Bloc d'empreinte PGP publique permettant l'échange sécurisé de correspondances confidentielles.

## 🚀 Utilisation & Déploiement Local

### Lancement en local

Puisque le projet est conçu en technologies Web standards sans étape de compilation requise, vous pouvez simplement :

1. Cloner ou télécharger le dépôt :
   ```bash
   git clone https://github.com/Fatakimuibu/Fatakimuibu.github.io.git
   cd Fatakimuibu.github.io
   ```
2. Double-cliquer sur `index.html` ou ouvrir le fichier dans n'importe quel navigateur moderne (Chrome, Edge, Firefox, Brave, Safari).
3. Ou lancer un serveur local léger (ex. avec VS Code *Live Server* ou en ligne de commande) :
   ```bash
   # Avec Python :
   python -m http.server 8000
   # Ou avec Node.js :
   npx serve .
   ```

### Déploiement sur GitHub Pages

Le site est nativement configuré pour être servi via **GitHub Pages** sur la branche `main` à la racine `/`.
